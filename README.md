## How to read this

- Registered participants are not submissions: typically only a fraction of registrants submit, so real odds are better than the ratio suggests.
- A very high ratio early in a hackathon usually drops as registrations grow; check again a week later.
- Some high-ratio events restrict eligibility (e.g. only company partners or students). Filter those out before you start.
